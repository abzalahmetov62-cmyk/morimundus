# Мобильный проигрыватель Morimundus

## Интерфейс и управление

Сенсорный режим включается автоматически на устройствах с основным указателем `pointer: coarse`. Проигрыватель занимает доступную высоту экрана и учитывает безопасные отступы. Основной режим — горизонтальный. В вертикальном режиме диалог располагается под видимой частью комнаты; инвентарь перестраивается в одну колонку.

- Основание и подвижная часть джойстика — отдельные изображения. Отклонение управляет направлением и скоростью движения; есть мёртвая зона и ограничение длины вектора.
- Движение и обзор работают одновременно. Для обзора используется отдельный палец на игровой области. Скользящее касание не выбирает предмет.
- Одна кнопка действия меняет рисунок между «Взять» и «Использовать». Учитывается текущая цель. Подходящее правило применения выбранной вещи имеет приоритет; иначе доступный для подбора объект берётся, остальные объекты открывают обычное взаимодействие, диалог, контейнер, дверь либо временное описание. Выбранная неподходящая вещь не блокирует разговор.
- Портфель открывает инвентарь. Активная ячейка выбирается внутри окна; выбранная вещь подписана в игровом режиме.
- Стрелка в игровом мире открывает меню. В диалоге — приостанавливает разговор. В окнах — возвращает назад; открытый из меню инвентарь возвращается в меню. Нативная история браузера не перехватывается.
- Инвентарь использует вертикальные вкладки справа: портфель — вещи, сердце — характеристики, мозг — навыки. На компьютере сохраняется прежнее управление клавиатурой и мышью.
- В горизонтальном режиме диалог находится слева, ответы — под повествованием, комната — справа. Камера пересчитывает пропорции оставшейся игровой области.
- В меню используются табличка MENU, настройки чтения, звук и существующие сохранения.
- При паузе, отмене жеста движения, смене ориентации, уходе в фон и загрузке локации сбрасывается удерживаемое движение. Потерянное касание не продолжает двигать героя после возврата.

## Ассеты

| Назначение | Файл интерфейса |
| --- | --- |
| Основание джойстика | `joystick-base.webp` |
| Подвижная часть | `joystick-thumb.webp` |
| Использовать | `use.webp` |
| Взять | `take.webp` |
| Инвентарь / вещи | `inventory.webp` |
| Меню | `menu.webp` |
| Назад | `back.webp` |
| Характеристики | `stats.webp` |
| Навыки | `skills.webp` |

Все девять ассетов находятся в `public/mobile-ui`. Исходные размеры, пиксели RGBA и прозрачность сохранены, проверено обратное декодирование WebP. Сжатие без потерь уменьшает загрузку; основные изображения управления предварительно загружаются при подготовке игры. Сенсорный режим ограничивает плотность отрисовки значением 1.25.

## Проверка

194 автоматических проверки: 19 новых сценариев мобильного управления и разметки, 175 прежних проверок движения, пространственных ограничений, диалогов, инвентаря, сохранений, проверок навыков и игрового цикла. Проверены аналоговое движение и столкновения, два одновременных жеста, отмена и захват указателя, пауза и фон, смена действия, три вкладки, расположение ответов и наличие всех ассетов.

Проверка типов TypeScript и производственная сборка выполнены. Браузерная проверка, реальная частота кадров и работа на физических Android/iPhone в этой среде недоступны. Эмуляция событий и серверный рендер React не заменяют проверку на телефоне.

Игровые данные, формат сохранений, публикация авторского сюжета и доступ к сайту не изменяются.
