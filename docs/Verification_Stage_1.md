# Проверка первого этапа Morimundus

Дата: 8 октября 2026.

Автор открывает мастерскую, меняет сведения о проекте и объектах, загружает рисунки и аудио, сохраняет проект и открывает его заново. Отдельное тестовое состояние позволяет менять флаги, присутствие объектов и время без изменения авторских данных.

| Граница | Результат | Доказательство |
| --- | --- | --- |
| Формат и ссылки проекта | Пройдено | Круговой обмен JSON сохраняет все виды данных; повреждённые ссылки, дубликаты и неизвестная версия отклоняются |
| Независимость прохождения | Пройдено | Изменение флага, присутствия объекта и полученного снимка не меняет проект или внутреннее состояние другой сессии |
| Общая пауза | Пройдено | Несколько причин паузы сочетаются; время продолжается только после снятия всех причин |
| Формат сохранения | Пройдено | Один экземпляр предмета не допускается в двух ячейках; неверный владелец и чужой проект отклоняются |
| Клиентские функции → API → D1 | Пройдено | HTTP-запись и независимое повторное чтение возвращают те же данные и новую версию |
| Конфликт вкладок | Пройдено | Устаревшая версия получает HTTP 409, свежий документ сохраняется |
| Ошибки записи | Пройдено | Повреждённый JSON, новая версия формата и межсайтовая запись отклоняются без изменения проекта |
| Загрузка → R2 → D1 → чтение | Пройдено | Изображение PNG и звук WAV загружаются; возвращаемые байты совпадают с SHA-256; ссылки сохраняются в проекте |
| Резервная копия | Пройдено | Содержит проект и байты ресурсов; проверяются хеши; восстановление в пустое хранилище меняет идентификаторы с сохранением всех ссылок |
| Восстановление после ошибки импорта | Пройдено на уровне функций | Повреждённые, неполные и некорректные копии отклоняются до изменения активного проекта |
| Страница собранного сайта | Пройдено | HTTP 200, серверная разметка содержит мастерскую и основные действия |
| Типы и сборка | Пройдено | TypeScript без ошибок; готов собранный Worker |
| Клики, внешний вид и клиентская гидратация в браузере | Не проверено | Допустимый инструмент браузерной проверки отсутствует; среда предварительного просмотра недоступна для HTTP-проверки |
| Браузерные WebMCP-инструменты | Не проверено в поддерживаемом браузере | Подключаются только при наличии document.modelContext; отсутствие поддержки не блокирует интерфейс |

Пройдены 10 проверок модели и резервных копий, 5 проверок API с локальными D1/R2 и проверка HTTP-страницы: всего 16. Последний прогон `node scripts/check-runtime.mjs` завершился успешно.

Обнаруженная ошибка записи метаданных ресурса исправлена: количество SQL-параметров приведено в соответствие с колонками. После исправления повторный прогон загрузил изображение и звук, сохранил их назначения и проверил полную резервную копию.

Работающие интерфейсные компоненты проверены по React Best Practices: устойчивые идентификаторы, независимые обновления черновика, обработка неуспешных запросов, защита новых правок при сохранении в процессе редактирования, семантические формы и подписи, клавиатурное управление стандартными диалогами и переключателями.

Управление камерой, полноценное проигрывание сцен, перенос предметов, приготовление, навыковые проверки и аккаунтные сохранения ещё не реализованы; в первой версии представлены их форматы и связи согласно плану.
