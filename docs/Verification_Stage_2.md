# Проверка второго этапа Morimundus

Дата: 8 октября 2026.

Кнопка «Проверить» открывает объёмное прохождение текущего авторского черновика. WASD/стрелки перемещают героя, мышь управляет взглядом, E открывает осмотр слева и приостанавливает мир, F подбирает доступный предмет, Esc возвращает курсор и открывает паузу. При запрете Pointer Lock доступен обзор удержанием левой кнопки мыши. Названия и подсветка объектов не показываются при наведении; доступны только обозначения E/F. ## Оставшийся браузерный маршрут

1. Открыть мастерскую → «Проверить» → «Войти в комнату». Проверить, что видна комната, движение свободное, все стены останавливают героя, по диагонали скорость сохраняется.
2. В свойствах крупного объекта включить «Препятствие для героя», назначить радиус и проверить, что его нельзя пересечь.
3. Назначить настоящий PNG с прозрачными полями. Обойти объект, посмотреть вверх/вниз; рисунок должен оставаться вертикальным. Проверить наведение рядом с силуэтом и через прозрачное поле на предмет позади.
4. Проверить E, окно слева и остановку мира; продолжить и убедиться, что подсказка возвращается. Подобрать бумагу по F: она должна исчезнуть из комнаты и появиться в одной ячейке. Закрыть проверку: авторская сцена сохраняется.
5. Проверить Esc, переход в другую вкладку, возврат, закрытие во время загрузки и два перезапуска подряд. Проверить отказ Pointer Lock и удержание кнопки мыши для обзора.

Дополнительная итерация исправлений по автоматическим результатам не требуется. Для окончательной приёмки второго этапа необходимо пройти этот маршрут; наличие реализации не заменяет эту проверку. Редактор комнат, размещение, текстуры и переходы относятся к этапу 3; ветвящиеся сценарии к этапу 4; выбор, выбрасывание и экипировка предметов к этапу 5.
